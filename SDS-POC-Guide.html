1. What is this POC?

This POC connects Docker with Niriksha AI to automatically monitor running containers and predict issues — without manually reading logs or checking stats.

Docker doesNiriksha AI does
Provides raw data — container state, logs, resource usage, volumes, portsAnalyzes the data and returns predictions, risk levels, and recommendations
Example: "Container 'api' restarted 5 times"Example: "Crash loop detected — likely memory leak. Recommend setting memory limit."

Supports both HTTP and gRPC transport to Niriksha AI. Controlled by one line in .env.

3. Values to Update in .env

The .env file lives in /opt/sds-poc/.env on the jumphost. Edit it before running.

# ── AI Transport ──────────────────────────────────────────────
TRANSPORT=http                          # Change to: grpc  (if using gRPC)

NIRIKSHA_TOKEN=<your-token-here>        # ← GET FROM: Niriksha team / portal

NIRIKSHA_HTTP_ENDPOINT=<url-here>       # ← GET FROM: Niriksha team (HTTP only)
NIRIKSHA_GRPC_ENDPOINT=<host:port>      # ← GET FROM: Niriksha team (gRPC only)

# ── Docker Connection ─────────────────────────────────────────
DOCKER_HOST=                            # Leave BLANK — same VM as Docker

5. Setup on Jumphost

1

Extract the tar file

mkdir -p /opt/sds-poc
cd /opt/sds-poc
tar -xzf /opt/SDS-POC-deploy.tar.gz
ls    # you should see: src/  package.json  tsconfig.json  .env  README.md
2

Install Node.js 18+

# Check if Node.js is already installed
node --version

# If not installed — run these:
curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -
sudo apt-get install -y nodejs
node --version      # should show v18.x or higher
3

Install project dependencies

cd /opt/sds-poc
npm install
4

Make sure your user can access Docker

docker ps                         # test access — if permission denied, run:
sudo usermod -aG docker $USER
newgrp docker                     # apply without logout
docker ps                         # verify it works now
5

Update .env with your token and endpoint values

nano /opt/sds-poc/.env

See Section 3 for what each value means and Section 4 for where to get them.

6

Build the project

cd /opt/sds-poc
npm run build     # compiles TypeScript → dist/
✅ If build succeeds with no errors, the POC is ready to run in mock mode. Plug in the SDK to get real AI analysis.

6. Integrating the Niriksha AI SDK

1

Download and install the SDK on jumphost

# If you received a .tgz file:
npm install ./niriksha-sdk-1.0.0.tgz

# If it's on an internal npm registry:
npm install niriksha-sdk
2

Edit HTTP transport — src/transports/http.ts

Find and replace the 3 TODO comment blocks:

// TODO 1 — top of file, replace:
// import { NirikshAI } from 'niriksha-sdk';
// WITH:
import { NirikshAI } from 'niriksha-sdk';

// TODO 2 — inside constructor, replace:
// this.client = new NirikshAI({ ... });
// WITH:
this.client = new NirikshAI({
  transport: 'http',
  token: process.env.NIRIKSHA_TOKEN,
  endpoint: process.env.NIRIKSHA_HTTP_ENDPOINT,
});

// TODO 3 — inside analyze(), replace:
// const response = await this.client.analyze(payload);
// WITH:
const response = await this.client.analyze(payload);
return {
  predictions: response.predictions,
  severity: response.severity,
  recommendations: response.recommendations,
};
ℹ Method name (analyze) and response fields depend on your SDK. Check the SDK docs and adjust accordingly.
3

Edit gRPC transport — src/transports/grpc.ts

Same as above — replace the same 3 TODO blocks, but use:

this.client = new NirikshAI({
  transport: 'grpc',
  token: process.env.NIRIKSHA_TOKEN,
  endpoint: process.env.NIRIKSHA_GRPC_ENDPOINT,
});
4

Build

npm run build

7. How to Run

After SDK is integrated

cd /opt/sds-poc
node dist/index.js

Before SDK (mock mode)

cd /opt/sds-poc
node dist/index.js
# Uses built-in mock analysis

Switch between HTTP and gRPC

Only change one line in .env — no rebuild needed:

TRANSPORT=http    # use HTTP
TRANSPORT=grpc    # use gRPC
